# Chatbot with Resume Chat Feature using LangGraph

This project allows users to interact with a chatbot and resume their previous conversations anytime.

The chatbot stores conversation history using LangGraph memory/checkpointing, enabling users to continue older chats instead of starting from scratch every time.

## Features
- Start new chat sessions
- Resume previous conversations
- Chat history persistence
- Context-aware responses
- LangGraph workflow integration
- LLM-powered responses
